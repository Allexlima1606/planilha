# 💰 Controle Financeiro PRO

Sistema web simples para controle de dívidas e parcelas pessoais.

O projeto permite cadastrar dívidas, acompanhar pagamentos, visualizar valores restantes e manter os dados salvos diretamente no navegador.

---

## 🚀 Funcionalidades

✅ Cadastro de dívidas  
✅ Edição de registros  
✅ Exclusão de dívidas  
✅ Pesquisa por credor  
✅ Filtro por status:
- Todas
- Em andamento
- Quitadas

✅ Cálculo automático:

- Valor total das dívidas
- Valor já pago
- Saldo restante
- Quantidade de dívidas

✅ Controle de parcelas

- Total de parcelas
- Parcelas pagas
- Parcelas restantes
- Valor da parcela

✅ Categorias:

- Cartão
- Financiamento
- Empréstimo
- Consórcio
- Outros

✅ Modo escuro

✅ Exportação para Excel

✅ Backup dos dados em JSON

✅ Restauração de backup

✅ Armazenamento local no navegador (LocalStorage)
